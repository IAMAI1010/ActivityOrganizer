# 头像与分享物料

小程序头像定稿方案：**立旗 + 三人并立**（集合出发），马卡龙抹茶配色（底 `#E7F3DF` / 符号 `#4A7A5C`，对比度 4.32:1）。

## 图标

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `ActivityOrganizer-icon-144.png` | 144×144 | **上传用**（微信公众平台推荐尺寸） |
| `ActivityOrganizer-icon-300.png` | 300×300 | 高清备用 |
| `ActivityOrganizer-icon-1024.png` | 1024×1024 | 印刷 / 海报 / 脚本源图 |
| `preview-final.png` | — | 微信内圆角 96 / 圆形 64 / 圆角 44 的显示效果预览 |

规格校验：正方形 RGB PNG，最小 2.9 KB（远低于 2MB 上限），图形安全边距 23.4%，圆角/圆形裁切不会切到旗杆或人物。

上传路径：`mp.weixin.qq.com` → 设置 → 基本设置 → 小程序头像 → 修改。**头像修改次数有限，确认后再传。**

小程序码中心的图案由微信按小程序头像自动生成，官方 `getUnlimitedQRCode` 没有设置中心 logo 的参数；正路是先上传头像，再到后台下载官方小程序码。

## 分享封面

| 文件 | 比例 | 用途 |
|---|---|---|
| `share-cover-5x4.png` | 1000×800，5:4 | `onShareAppMessage` 的 `imageUrl`（转发给朋友） |
| `share-cover-1x1.png` | 1000×1000，1:1 | `onShareTimeline` / 收藏 |

小程序详情页 `pages/detail/detail.js` 目前两个分享回调都用 `activity.cover_url || undefined`：活动没封面时会退化为页面截图，且 5:4 与 1:1 共用一张图必有一处被裁切。这两张品牌图可作兜底——两个回调分别指向对应比例的图片即可（**按「保持小程序端简洁」的决定，源码未改动**）。

转发自定义图需基础库 ≥ 1.5.0，朋友圈分享需 ≥ 2.11.3，具体以微信官方文档为准。

## 小程序码海报

| 文件 | 说明 |
|---|---|
| `poster-template.png` | 800×1200 模板，中间是明确标注的虚线占位框 |
| `poster-demo.png` | 合成效果示例，带红色「示例占位 · 不可用于发布」警示条，**不要当正式物料使用** |

拿到官方小程序码后合成正式海报：

```bash
python build_materials.py --code 官方小程序码.png
# 产出 poster-with-code.png
# 可选：--overlay-logo 把头像叠到码中心，--logo-ratio 调占比
# 叠加后务必用微信真机扫码验证识别率再印刷
```

## 脚本

两个脚本都以**自身所在目录**为输出基准（`os.path.dirname(__file__)`），可直接在本目录重跑，无外部图片依赖：

- `build_icon.py` — 纯代码绘制 V4 图形，重建 144/300/1024 图标与 `preview-final.png`
- `build_materials.py` — 生成两张分享封面、海报模板与示例；`--code` 合成正式海报

依赖：`Pillow`（`build_materials.py` 的二维码贴图另需可读的 PNG 输入）。改配色改脚本顶部的色值常量即可。

> 图形设计经验：三个人形要做成「圆头压在半圆肩上、颈部留凹口、头肩连成一体」。独立圆头 + 独立胶囊身体在 44px 下会被读成 6 个圆点；把三人塞进图钉容器在小尺寸下也必然糊成纹理，这是最终放弃图钉的原因。
